GitHub 网页版上传指南（不用装 Git！）

第 1 步：创建仓库
  1. 打开 github.com → 登录
  2. 点右上角 ➕ → New repository
  3. 仓库名：miao-relay
  4. 选 Public
  5. ✅ 勾选 Add a README file
  6. 点 Create repository
第 2 步：开启 Actions 权限
  1. 进仓库 → Settings → Actions → General
  2. 找到 Workflow permissions
  3. 选 Read and write permissions
  4. 点 Save
第 3 步：上传文件（按下面列表逐个建）

点 Add file → Create new file → 文件名写完整路径 → 粘贴内容 → Commit

📁 .github/workflows/build_all.yml
📁 windows/main.py
📁 windows/_config_default.json
📁 windows/requirements.txt
📁 apk/main.py
📁 apk/buildozer.spec
📁 apk/requirements.txt
📁 .gitignore
📁 README.md
📁 LICENSE
📁 QUICKSTART.md
💡 懒人技巧：去 模板仓库 点 Use this template → 填名字 → Create → 自动拥有所有文件！
第 4 步：触发打包
  1. 点顶部 Actions
  2. 左边选 打包 EXE+APK 并发布 Release
  3. 右边点 Run workflow → 选 main → 点 Run workflow
第 5 步：等 20 分钟 → 下载成品
  • ✅ Actions 变绿 = 成功
  • 点 Releases → 下载 喵提醒中转.exe + miaoremind-debug.apk
